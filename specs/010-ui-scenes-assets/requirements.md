# Requirements — UI, Scenes & Assets

## Objetivo
Construir la interfaz de escritorio y el flujo visual de la partida.

## Requisitos
- R1. Crear MenuScene.
- R2. Crear GameplayScene.
- R3. Crear PauseScene.
- R4. Crear VictoryScene.
- R5. Crear GameOverScene.
- R6. Mostrar puntuación.
- R7. Mostrar vidas.
- R8. Mostrar tiempo.
- R9. Mostrar nivel.
- R10. Mostrar objetivos.
- R11. Usar colores vivos y llamativos.
- R12. Crear AssetManager.
- R13. Crear AudioManager.
- R14. Evitar que entidades carguen assets directamente.

## Criterios de aceptación
- El usuario puede iniciar una partida desde el menú.
- Puede pausar.
- Puede terminar en victoria o derrota.
- Los datos principales se actualizan visualmente.
- Los assets se cargan mediante un gestor centralizado.
