# Requirements — Time, Difficulty & Levels

## Objetivo
Implementar tiempo dinámico y progresión de dificultad.

## Requisitos
- R1. Cada nivel debe tener duración configurable.
- R2. Mostrar tiempo restante.
- R3. La dificultad debe aumentar progresivamente.
- R4. La velocidad debe aumentar a medida que disminuye el tiempo.
- R5. La frecuencia de aparición puede aumentar.
- R6. La probabilidad de bombas puede variar por nivel.
- R7. Los niveles deben tener objetivos medibles.
- R8. El nivel debe terminar por victoria o derrota.
- R9. Los parámetros deben ser configurables.

## Criterios de aceptación
- El tiempo disminuye de forma continua.
- La dificultad cambia conforme avanza la partida.
- El cambio de velocidad es observable.
- Un objetivo cumplido puede producir victoria.
- Agotarse el tiempo puede producir derrota si el objetivo no fue cumplido.
