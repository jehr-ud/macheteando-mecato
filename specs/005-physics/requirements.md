# Requirements — Physics System

## Objetivo
Actualizar la posición de entidades móviles.

## Requisitos
- R1. Procesar Transform + Velocity.
- R2. Aplicar velocidad durante cada frame.
- R3. Aplicar gravedad configurable.
- R4. Permitir trayectorias parabólicas.
- R5. No crear entidades.
- R6. No calcular puntuación.

## Criterios de aceptación
- Una entidad con velocidad se desplaza.
- Una entidad lanzada con gravedad produce una trayectoria parabólica.
- Los valores pueden probarse sin render.
