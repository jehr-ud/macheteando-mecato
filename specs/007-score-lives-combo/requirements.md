# Requirements — Score, Lives & Combo

## Objetivo
Implementar puntuación, vidas y combos.

## Requisitos
- R1. Cada jugador debe tener puntuación.
- R2. El máximo de vidas iniciales es 5.
- R3. Cortar mecato suma puntos.
- R4. Cortar bombas genera penalización.
- R5. Permitir combos.
- R6. Permitir multiplicadores configurables.
- R7. Mostrar cambios de puntuación y vidas.
- R8. No permitir vidas mayores a 5.

## Criterios de aceptación
- La puntuación se actualiza correctamente.
- Las vidas se mantienen entre 0 y 5.
- Un corte válido puede incrementar combo.
- Una penalización puede reiniciar combo.
