# Prompt compacto para implementar una spec

Implementa la specification `{{SPEC_ID}}` ubicada en `specs/{{SPEC_ID}}`.

Antes de modificar código:

1. Lee `agents.md`.
2. Lee `requirements.md`.
3. Lee `specs/{{SPEC_ID}}/requirements.md`.
4. Lee `specs/{{SPEC_ID}}/design.md`.
5. Lee `specs/{{SPEC_ID}}/tasks.md`.
6. Inspecciona el código existente.

Después:

- implementa las tareas en orden;
- respeta ECS + Entity Factory + Systems;
- no introduzcas funcionalidades fuera de la spec;
- ejecuta las pruebas;
- corrige los errores;
- valida los criterios de aceptación.

No marques tareas como completadas sin evidencia.

Al terminar informa qué cambió, qué tests pasaron y qué quedó pendiente.
